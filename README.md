# Mrinmoy Debnath Portfolio

A responsive personal portfolio website for showcasing skills, projects, education, certifications, and contact information. The site is built with plain HTML, CSS, and JavaScript, making it lightweight, easy to customize, and simple to deploy on static hosting platforms.

## Overview

This portfolio presents Mrinmoy Debnath as a Computer Science Engineering student with interests in software development, data science, machine learning, business intelligence, and practical project building.

The design focuses on a clean professional layout, readable content, smooth responsiveness, and a polished light theme with optional dark mode.

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Light theme by default with a dark mode toggle.
- Sticky navigation with mobile menu support.
- Project filtering by category: Top, Python, Java, ML, and DA.
- Featured project view for selected top projects.
- Dedicated sections for About, Core Capabilities, Projects, Credentials, and Contact.
- Contact form powered by Formspree.
- Resume download button.
- Accessible focus states, skip link, semantic HTML, and descriptive labels.
- SEO-friendly title, description, and Open Graph metadata.
- Reuses local assets from the main `assets` folder.

## Getting Started

1. Open the `optimized-portfolio` folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to review each section.

No build step or package installation is required.

## Customization

- Update personal details in `index.html`.
- Add or remove projects inside the Projects section.
- Mark a project as featured by adding `data-featured="true"` to its project card.
- Update colors, spacing, and responsive behavior in `style.css`.
- Adjust menu, theme, and filtering behavior in `script.js`.
- Replace resume or images in the parent `assets` folder if needed.
