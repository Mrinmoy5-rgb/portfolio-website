## ⚙️ Run Locally

No package installation or build step is required.

### 1. Clone the repository

```bash
git clone https://github.com/Mrinmoy5-rgb/portfolio-website.git
```

### 2. Enter the project directory

```bash
cd portfolio-website
```

### 3. Open the website

Simply open:

```text
index.html
```

in a modern web browser.

For local development, you can also use the **Live Server** extension in VS Code.

---

## 🎨 Customization

The portfolio is intentionally built with plain HTML, CSS, and JavaScript so that it can be easily modified.

### Update personal information

Edit:

```text
index.html
```

### Update design

Edit:

```text
style.css
```

### Update interactions

Edit:

```text
script.js
```

### Add or modify projects

Project cards can be edited directly inside the Projects section of `index.html`.

Categories are controlled using attributes such as:

```html
data-category="ml python"
```

Featured projects can be marked using:

```html
data-featured="true"
```

### Replace assets

Images, icons, and the resume can be replaced inside:

```text
assets/
```
